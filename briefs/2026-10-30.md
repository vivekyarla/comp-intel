## Market briefing
Vendors are giving agents fixed, governed paths to act on: AWS now lets agents call existing Step Functions workflows that run every step as defined, and Salesforce is pointing Agentforce and Claude at one shared semantic layer so "pipeline" means the same thing everywhere. Spend reporting for AI is also moving into APIs.

- Oct 29: AWS Step Functions workflows can be used as agent tools through Bedrock AgentCore Gateway (MCP). The agent picks when to run a workflow and what to pass; Step Functions runs each step, such as an approval, in the same order every time. [AWS](https://aws.amazon.com/about-aws/whats-new/2026/10/step-functions-workflows-ai-agent-tools/)
- Oct 29: a Salesforce developer guide shows Agentforce and Claude (via Tableau Next MCP) answering the same open-pipeline question from one Tableau semantic model on Data 360, with Data 360 governance tags and policies controlling access. [Salesforce Developers](https://developer.salesforce.com/blogs/2026/10/build-trusted-conversational-analytics-with-aiforce-data-360-and-tableau-semantics)
- Oct 29: Anthropic launched a Usage and Cost Analytics API in beta that reports Claude token usage and cost by model, workspace, API key and user or service account; the older usage and cost endpoints are now legacy. [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview)
