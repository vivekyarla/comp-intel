## Market briefing
CRM agents moved further into default packaging and admin controls over the weekend: Salesforce put Agentforce Coworker into its small-business suites at no added cost, Close opened agents that fire on schedules or CRM events, and Clay let enterprises run its AI through their own AWS accounts.

- Nov 23: Agentforce Coworker is now included in Salesforce Starter and Pro Suite for new and existing customers and trialists, with no setup or added cost; it answers pipeline questions, drafts follow-ups and shows each record change for approval before saving. [Salesforce](https://www.salesforce.com/blog/small-business/agentforce-coworker-in-salesforce-suites/)
- Nov 21: Close's General Agents (beta) run on a schedule or when a lead, opportunity, call, meeting or form event fires, act with the creator's permissions, pause for approval on tools that aren't pre-approved, and bill in AI credits. [Close Help Center](https://help.close.com/feature-guide/agents/general-agents)
- Nov 20: Clay's Amazon Bedrock connection sends supported Clay AI actions through the customer's own AWS account using short-lived, IAM-scoped credentials instead of a stored key. [Clay](https://www.clay.com/blog/use-your-amazon-bedrock-connection-in-clay)

## What changed
1. **Salesforce brings Agentforce Coworker to Starter and Pro Suite** — NEW. Nov 23: Coworker is built into Salesforce's small-business suites for new and existing customers and trialists, with no setup or added cost. It answers questions like what changed in the pipeline this week, drafts follow-ups, recommends priorities across opportunities and cases, and lists planned field changes for approval before saving. [Salesforce](https://www.salesforce.com/blog/small-business/agentforce-coworker-in-salesforce-suites/)
2. **Clay lets enterprises run its AI through their own Amazon Bedrock** — NEW. Nov 20: supported Clay AI and agent actions can run on Bedrock in the customer's AWS account. Access uses OpenID Connect federation and an IAM role bound to one Clay workspace and connection, so no long-lived AWS key; set up through a Clay Growth Strategist and the customer's AWS admin. [Clay](https://www.clay.com/blog/use-your-amazon-bedrock-connection-in-clay)
3. **Close launches General Agents in beta** — NEW. Nov 21: Close users describe a task and set a schedule or CRM-event trigger; agents can update leads and opportunities, send email and SMS and create tasks with pre-approved tools, otherwise pausing for approval. Agents inherit the creator's permissions; beta orgs get 250 free AI credits a week. [Close Help Center](https://help.close.com/feature-guide/agents/general-agents)
4. **Lightfield connects OneDrive and SharePoint to its agent** — NEW. Nov 20: files and folders from OneDrive and SharePoint can be attached to records and used by Lightfield's agent; the Files API can import meeting recordings and transcripts up to 512 MB. [Lightfield](https://lightfield.com/blog/onedrive-sharepoint-integration-team-member-filter-and-more)
