## Market briefing
CRM work is moving into general-purpose assistants: ServiceNow now lets sellers update deals and build quotes from Gemini Enterprise, and Oracle is bringing its applications into ChatGPT under each customer's permissions and approvals. Slack, meanwhile, is giving agents shared channels for longer jobs instead of private chats.

- ServiceNow CRM integrations with Gemini Enterprise are generally available as of Oct 27: sellers can ask for account context and recent deal activity, update opportunity notes, create follow-ups and build configurations and quotes in natural language. ServiceNow connects them through MCP servers and Agent2Agent (A2A). [ServiceNow](https://newsroom.servicenow.com/press-releases/details/2026/ServiceNow-and-Google-Cloud-advance-agentic-AI-for-industry-workflows/default.aspx)
- OpenAI and Oracle said on Oct 27 that Oracle is developing Oracle AI Workspace to run approved Oracle workflows inside ChatGPT. U.S. Oracle customers can now buy the OpenAI API, Codex and ChatGPT Work through Oracle Marketplace with eligible Oracle Universal Credits. [OpenAI](https://openai.com/index/oracle-apps-in-chatgpt)
- Slack published a build guide for the Slack Code API on Oct 28. Agents can open a code channel from a conversation, post diffs, HTML previews and canvases, and archive the session with a summary. A Salesforce survey of 250 U.S. executives published Oct 27 found 59% see work stall each week because it sits in one person's AI tool. [Slack Developers](https://slack.dev/build-with-slack-code-api/) · [Salesforce](https://www.salesforce.com/news/stories/work-stalls-isolated-ai-tools/)
