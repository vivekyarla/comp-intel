## Market briefing
AI usage is being sold as one metered pool across chat and agent work: OpenAI will put ChatGPT and Codex on a single token allowance in December. Model vendors are also switching on invisible text watermarks by default ahead of the EU AI Act's December deadline.

- Nov 1: OpenAI's updated help page says that from December, Plus, Pro and Business usage will be shared across ChatGPT and Codex and measured in tokens. Instant chat does not count; users who hit the limit can wait, upgrade or buy credits. [OpenAI Help Center](https://help.openai.com/en/articles/20001625-understanding-chatgpt-and-codex-usage-limits) · [The Decoder](https://the-decoder.com/openais-upcoming-chat-and-work-merger-in-chatgpt-signals-the-end-of-all-you-can-prompt-pricing/)
- Oct 31: Anthropic told API customers it will watermark Claude Mythos 5, Opus 4.7, Opus 4.6 and Sonnet 4.6 (newer models already carry it); customers can't turn it off, and on Opus 4.6 and Sonnet 4.6 it applies only at default sampling settings. xAI's docs say Grok API text is watermarked by default from Nov 7, with a per-model admin opt-out. [The Decoder](https://the-decoder.com/anthropics-watermark-rollout-leaves-a-loophole-on-two-older-claude-models/) · [xAI docs](https://docs.x.ai/developers/advanced-api-usage/watermarking)
- Oct 30–Nov 2: Anthropic confirmed it added two sentences to Claude Code's Opus 5.5 prompt to steer it away from recreating specific existing games; developers report reverse-engineering refusals since Oct 31, which Anthropic has not addressed. [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropic-confirms-new-claude-code-limits-to-prevent-game-cloning-users-report-opus-5-5-is-also-actively-blocking-reverse-engineering-tasks)
