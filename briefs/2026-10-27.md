## Market briefing
Agent spend is getting its own controls: the platforms that run sales agents are adding budget caps, kill switches and per-task model routing, while revenue vendors move from task-level AI to agent-run plays with human approval points.

- Salesforce made a FinOps Dashboard, Model Wallet hard spending limits, Cost Optimization Policies and an Agent Kill Switch generally available in Agent Fabric on Oct 27; Agent Evals and API Evals, which can trigger the kill switch when quality slips, enter beta in November. [Salesforce](https://www.salesforce.com/news/stories/agent-fabric-catch-failures-control-ai-costs/)
- Salesloft's Agentic Playbook lets revenue operations define sales plays in natural language and set the objectives, guardrails, autonomy level and human-review points for each play; it is entering early access. [Salesloft via GlobeNewswire](https://www.globenewswire.com/news-release/2026/10/27/3389102/0/en/salesloft-advances-agentic-revenue-vision-with-new-ai-capabilities-for-sales-teams.html)
- Clay made auto-mode the default for new Claygents: a post-trained router picks a model per row, which Clay says cost 47% less on production traffic than always using the most capable model. [Clay](https://www.clay.com/blog/automode-for-claygent)
